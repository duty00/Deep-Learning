# Reports

- `tables/` – aggregated results generated by `scripts/aggregate_results.py` and `scripts/analyze_results.py`
  (CSV and LaTeX). Do not edit by hand; regenerate from `outputs/`.
- `figures/` – EDA figures (`notebooks/01_eda.ipynb`) and analysis figures (recall heatmap, reliability
  diagram, confusion matrices).
- `RESULTS_DRAFT.md` – working draft of the Results section (E1–E7).

The final report is written in English with the official Springer LNCS template (margins and font sizes
unchanged). Every number in the report must trace back to a run listed in `experiments/results.csv`.
